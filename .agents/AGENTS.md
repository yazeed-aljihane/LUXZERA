# LuxZera Design System Rules

## Spacing: 8px Grid
All spacing values MUST snap to the 8px grid: **8, 16, 24, 32, 48, 64, 80, 96**.
No random values like 11px, 13px, 17px, 28px, etc.

## Typography Scale (Fewer Sizes)
Use only these font sizes: **12, 14, 16, 20, 32, 48**.
Everything derives from this scale. Never introduce arbitrary sizes.

## Color Palette (Fewer Colors)
- **White/Background**: `#FAFAF9`, `#FFFFFF`
- **Orange (Brand)**: `#F07020`
- **Dark Text**: `#37352F`
- **Muted Text**: `#9B9B9B`
- **Border**: `#ECECEC`, `#E7E3DD`
- **Gold Accent**: `#C6A15B`
Avoid introducing new colors without explicit approval.

## Contrast Hierarchy
Every page/section must have clear levels:
1. **Primary** — highest contrast, largest visual weight
2. **Secondary** — medium contrast
3. **Tertiary** — lighter, supporting
4. **Muted** — lowest contrast, least important

## Visual Weight Over Size
Importance is communicated through contrast, white space, position, and density — not just making things bigger.

## Optical Alignment
Align elements visually, not mathematically. Icons beside text often need 1–2px vertical offset to appear centered to the human eye.

## White Space Is A Component
Every gap must be intentional. White space creates pause, hierarchy, and breathing room. It is never "empty."

## Rhythm & Consistency
Repeating spacing, radius, and typography values creates trust and premium feel. Every repeated pattern reinforces the brand.

## Every Pixel Must Earn Its Place
Before adding any element, ask: Does it improve clarity, hierarchy, or usability? If no, remove it.
